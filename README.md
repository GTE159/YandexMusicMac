# YandexMusicMac

Ультра-легковесный, полностью нативный десктопный клиент Яндекс Музыки под macOS (**Apple Silicon ARM64 & Intel x86_64 — Universal 2**), написанный на Swift 6 и SwiftUI.

Обеспечивает полный функционал стриминга («Моя волна», «Мне нравится», плейлисты, поиск, выбор качества до FLAC Lossless, синхронизированные караоке-субтитры LRC). Глубоко интегрирован с macOS и потребляет экстремально мало ОЗУ (45–65 МБ) при практически нулевой нагрузке на процессор в фоне — без Electron, WebKit и тяжелых обёрток.

> **Обратите внимание:** данный клиент был разработан с помощью ИИ для личного пользования и максимальной энергоэффективности на macOS, но опубликован в открытый доступ для всех, кому нужен быстрый и компактный плеер.

## Ключевые особенности

* **Экстремальная легковесность:** Потребление ОЗУ всего 45–65 МБ благодаря аппаратному даунсемплингу обложек через `ImageIO`, лимитированному кэшированию `NSCache` и разделению поисковых буферов.
* **Поддержка Apple Silicon и Intel:** Сборка в виде Universal 2 binary — приложение работает нативно как на чипах Apple Silicon (M1/M2/M3/M4), так и на процессорах Intel.
* **Zero-WebKit Auth:** Авторизация через системное окно OAuth с мгновенным перехватом токена и гарантированной выгрузкой WebKit-процессов сразу после входа.
* **Двойной аудиопротокол и криптография:** Параллельное разрешение потоков (`/get-file-info` с HMAC-SHA256 подписью через `CryptoKit` и каталог `/download-info` с MD5-подписью) с поддержкой Hi-Res FLAC Lossless и 320 kbps MP3/AAC.
* **«Моя волна» v2 + v1:** Бесконечный персональный поток на современном протоколе Rotor Session v2 с бесшовным fallback на v1 и полной телеметрией (`radioStarted` -> `trackStarted` -> `trackFinished` / `skip` / `like` / `dislike`).
* **Синхронизированные субтитры (Караоке LRC):** Отображение таймированного текста песен с настраиваемым расположением (справа или над панелью плеера) и плавной анимацией подсветки активных строк.
* **Системная интеграция macOS:** Нативная поддержка мультимедийных клавиш клавиатуры, Touch Bar, наушников AirPods и системного виджета управления воспроизведением в **Control Center** / Now Playing (`MPNowPlayingInfoCenter` / `MPRemoteCommandCenter`).
* **Кросс-версионность:** Поддержка macOS 14.0 (Sonoma), macOS 15.0 (Sequoia) и новее, сборка через чистый Command Line Tools (CLT) без обязательной установки тяжелого Xcode.

## Установка готового релиза

Скачайте архив последней версии со страницы [Releases](https://github.com/GTE159/YandexMusicMac/releases):

* **`YandexMusicMac-v1.0.0-universal.zip`** — Универсальная версия (рекомендуется, работает нативно и на Apple Silicon, и на Intel).
* **`YandexMusicMac-v1.0.0-arm64.zip`** — Оптимизирована специально под Apple Silicon (M1/M2/M3/M4).
* **`YandexMusicMac-v1.0.0-x86_64.zip`** — Для Mac на процессорах Intel.

Распакуйте архив и переместите `YandexMusicMac.app` в папку `/Applications` («Программы»).

> [!TIP]
> При первом запуске macOS может заблокировать запуск неподписанного разработчиком приложения через Gatekeeper. Чтобы разрешить запуск:
> 1. Кликните правой кнопкой мыши по `YandexMusicMac.app` в Finder и выберите **«Открыть»** -> **«Открыть»**.
> 2. Или выполните в терминале команду снятия карантина:
>    ```bash
>    xattr -cr /Applications/YandexMusicMac.app
>    ```

## Сборка из исходников

### Требования
* macOS 14.0+
* Xcode Command Line Tools или Xcode 16+ (Swift 6.0+)

### Клонирование и сборка
```bash
# 1. Клонирование репозитория
git clone https://github.com/GTE159/YandexMusicMac.git
cd YandexMusicMac

# 2. Сборка приложения .app (по умолчанию собирается Universal binary):
./scripts/build_app.sh

# Или сборка под конкретную архитектуру:
./scripts/build_app.sh arm64    # Apple Silicon
./scripts/build_app.sh x86_64   # Intel

# 3. Сборка всех релизных архивов:
./scripts/package_releases.sh
```

Готовое приложение будет создано в корне проекта: `YandexMusicMac.app`.

## Стек технологий

* **Язык:** Swift 6 (с активным режимом `StrictConcurrency`)
* **Интерфейс:** SwiftUI + AppKit
* **Аудиодвижок:** `AVFoundation` (`AVPlayer`, `AVPlayerItem`), кастомная очередь треков, дедупликация Rotor
* **Сетевой слой:** `URLSession` с кастомным пулингом соединений и потоковым кэшем
* **Безопасность:** macOS Keychain Services (`Security.framework`) для безопасного хранения токена
* **Тестирование:** `Swift Testing` (48 юнит-тестов ядра `YMCoreTests`)
