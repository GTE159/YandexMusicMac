# flow~ (YandexMusicMac)

Легковесный нативный неофициальный клиент Яндекс Музыки под macOS (14+, Apple Silicon & Intel), созданный на Swift 6 и SwiftUI.

<img width="590" height="341" alt="Screenshot 2026-11-23 at 23 03 03" src="https://github.com/user-attachments/assets/aa2cad9d-bbdf-4394-a444-d2e81237b5f2" />


Обеспечивает полный функционал стриминга: «Моя волна» с персональными подборками и настроениями, «Чарт», «Мне нравится», создание и редактирование плейлистов, поиск, 10-полосный системный эквалайзер, кроссфейд, выбор качества до FLAC Lossless и полноэкранные синхронизированные караоке-субтитры (LRC). Глубоко интегрирован с macOS и потребляет экстремально мало ОЗУ при околонулевой фоновой нагрузке CPU.

Клиент предоставляет возможность прослушивания личной библиотеки Яндекс Музыки (и прочих фишек официального приложения) без возможности скачивания треков в чистом виде. Скачанные внутри данного приложения треки (альбомы и плейлисты, а также их метаданные) можно прослушивать/смотреть только внутри него самого. Для его использования покупайте официальную подписку Яндекс Плюс на их сайте, без неё клиент не будет воспроизводить какую-либо музыку вообще.

> **ПРОШУ УЧЕСТЬ:** я не являюсь каким-либо разработчиком (тем более на swift) и данное приложение было написано с помощью ИИ (так что оно попадает под определение AI-slop'а). Делал в своё свободное время для себя и тех, кого не устраивает потребление ресурсов официальной приложухи Яндекса. Сам я не разбираюсь в технических нюансах, я лишь давал установки и обкатывал в daily-use. Это вторая версия с обновлённым дизайном и кучей новых фишек и баг-фиксов разного рода.

## Ключевые особенности

* **Нативность и низкий расход ОЗУ:** Аппаратный даунсемплинг обложек через `ImageIO`, лимитированное кэширование `NSCache`, 5 сбалансированных цветовых тем (Системная, Графитовая, Полночь, Светлая, Тёплый песок), адаптивность до минимального окна `440×320 pt` и закреплённые верхние шапки с перетаскиванием окна.
* **Поддержка Apple Silicon и Intel:** Сборка в виде Universal 2 binary — приложение работает нативно как на чипах Apple, так и Intel.
* **Безопасное хранилище и минимальные права OAuth:** Вход по OAuth Device Flow («Код устройства» / QR-код), через эфемерное окно Яндекс ID с мгновенной выгрузкой WebKit-процессов или вручную по токену; запрашиваются только права Музыки (`music:content music:read music:write` с автоматическим fallback при `invalid_scope`), а токен шифруется на диске через AES-256-GCM + HKDF-SHA256 (`CryptoKit`).
* **10-полосный системный эквалайзер и Crossfade:** Real-time DSP на базе `MTAudioProcessingTap` + `kAudioUnitSubType_NBandEQ` (9 пресетов, предусиление, плавная стеклянная карточка в плеере по `⌘E`) и плавное сведение треков (Crossfade 0–12 с).
* **Двойной аудиопротокол и криптография:** Параллельное разрешение потоков (`/get-file-info` с HMAC-SHA256 подписью через `CryptoKit` и каталог `/download-info` с MD5-подписью) с поддержкой Hi-Res FLAC Lossless и 320 kbps MP3/AAC.
* **Зашифрованный офлайн-режим («Скачанное»):** Загрузка треков, альбомов и плейлистов в локальный AES-256-GCM кэш с воспроизведением без интернета, офлайн-обложками и текстами песен.
* **«Моя волна» v2 + v1 и «Сохранённые волны»:** Единый хаб «Поток и настроение» на протоколе Rotor Session v2 с 4-уровневым fallback, каталогом жанров, диагностикой в настройках и снимками любимых направлений с неизменяемостью при обычном прослушивании.
* **Управление плейлистами:** Создание новых плейлистов (название, описание, приватность), редактирование, удаление и быстрое добавление любых треков через контекстное меню.
* **Полноэкранный «Сейчас играет» и субтитры (Караоке LRC):** Синхронизированный текст песен в полноэкранном режиме поверх атмосферного размытого фона обложки или в компактной полосе над плеером с мгновенным переключением режимов.
* **Системная интеграция macOS:** Нативная поддержка мультимедийных клавиш, наушников AirPods, Touch Bar и системного виджета **Control Center** / Now Playing с передачей очереди (`MPNowPlayingInfoCenter` / `MPRemoteCommandCenter`).
* **Кросс-версионность:** Поддержка macOS 14.0+ (Sonoma) и новее, сборка через чистый Command Line Tools (CLT) без обязательной установки Xcode.

## Установка готового релиза

Скачайте архив последней версии со страницы [Releases](https://github.com/GTE159/YandexMusicMac/releases):

* **`flow~-v2.2-universal.zip`** — Универсальная версия (работает нативно и на Apple Silicon, и на Intel).
* **`flow~-v2.2-arm64.zip`** — Специально под Apple Silicon.
* **`flow~-v2.2-x86_64.zip`** — Для Mac на процессорах Intel.

Распакуйте архив и переместите `flow~.app` в папку `/Applications` («Программы»).

> [!TIP]
> При первом запуске macOS может заблокировать запуск неподписанного разработчиком приложения через Gatekeeper. Чтобы разрешить запуск:
> 1. Кликните правой кнопкой мыши по `flow~.app` в Finder и выберите **«Открыть»** -> **«Открыть»**.
> 2. Или выполните в терминале команду снятия карантина:
>    ```bash
>    xattr -cr /Applications/flow~.app
>    ```

## Сборка из исходников

### Требования
* macOS 14.0+
* Xcode Command Line Tools или Xcode 16+ (Swift 6.0+)

### Клонирование и сборка
```bash
# 1. Клонирование репозитория
git clone https://github.com/GTE159/YandexMusicMac.git
cd YandexMusicMac

# 2. Сборка приложения .app (по умолчанию собирается Universal binary):
./scripts/build_app.sh

# Или сборка под конкретную архитектуру:
./scripts/build_app.sh arm64    # Apple Silicon
./scripts/build_app.sh x86_64   # Intel

# 3. Сборка всех релизных архивов:
./scripts/package_releases.sh
```

Готовое приложение будет создано в корне проекта: `flow~.app`.

## Список технологий

* **Язык:** Swift 6 (с активным режимом `StrictConcurrency`)
* **Интерфейс:** SwiftUI + AppKit
* **Аудиодвижок:** `AVFoundation` (`AVPlayer`, `AVPlayerItem`), `MediaToolbox` (`MTAudioProcessingTap`) + `AudioToolbox` (`kAudioUnitSubType_NBandEQ`), Crossfade, постраничная догрузка очередей
* **Сетевой слой:** `URLSession` с кастомным пулингом соединений и потоковым кэшем
* **Безопасность:** `CryptoKit` (AES-256-GCM + HKDF-SHA256 на базе аппаратного идентификатора Mac)
* **Тестирование:** `Swift Testing` (94 юнит-теста ядра `YMCoreTests`)
